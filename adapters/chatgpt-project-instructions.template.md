# ChatGPT Project Instructions — BUAP adapter

Use `chatgpt-projects/buddy/00_PROJECT_INSTRUCTIONS_PASTE.md` for the full Buddy
Project setup.

If the project has a smaller instruction window, use `BUAP_STANDARD.md` and upload the
knowledge files from `chatgpt-projects/buddy/knowledge/` as project files.

## Optional overlays

When helpful, include Ponytail and Caveman as optional overlays:

- `DietrichGebert/ponytail` for simpler, smaller, native-first implementation discipline.
- `JuliusBrussee/caveman` for terse technical communication.

Apply them after BUAP and project/repo instructions. Never let them override safety,
validation, source-of-truth, privacy, or repo-local rules.
