# ChatGPT Personalization Exports

These files are generated from BUAP source material for ChatGPT account/project setup.

They are **pasteable exports**, not proof that ChatGPT account settings or saved memories were updated automatically. ChatGPT account-level memory and custom instructions may require manual paste/confirmation in the ChatGPT UI.

## Files

| File | Use |
|---|---|
| `custom-instructions.md` | Paste into ChatGPT Custom Instructions / Personalization. |
| `memory-candidates.md` | Safe Saved Memory candidates to add one-by-one. |
| `hooks.md` | Routing/hooks rules for ChatGPT Projects or custom GPT instructions. |
| `projects/prismtek-project-instructions.md` | Project instructions for the Prismtek / Cody workroom. |
| `projects/taylor-project-instructions.md` | Project instructions for the Taylor shared/collaborative workroom. |

## Source order

These exports follow BUAP's current source order:

1. `knowledge-vault` — durable memory, Vegapunk Brain, Memory Engine, graph/search/index/context bundles.
2. `buddy-brain` — operator policy, routines, council roles, response posture, cross-repo coordination.
3. `buddy-agent` — guarded execution, action risk, approvals, receipts.
4. `omni-buddy` — local device voice/vision/transport runtime.
5. `prismtek-apps` — product UX, apps, games, Prismcade, playable builds.
6. `buddy-universal-agent-profile` — portable behavior profile, adapters, conformance, handoff standards.

## Safety

Do not paste secrets, tokens, credentials, private local paths, browser session state, raw private prompts, camera/audio private data, raw transcripts, or private repo details into ChatGPT memory or public docs.
