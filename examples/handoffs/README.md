# BUAP Handoff Examples

These examples show how Buddy should hand work to another agent or human when direct
execution is unavailable or when a specialist tool is better suited.

## Examples

- `claude.md`
- `codex.md`
- `chatgpt.md`
- `human-developer.md`
- `pr-repair.md`
- `repo-migration.md`
- `blocked-missing-tool.md`

## Rule

A handoff is successful when the next agent can start without asking “what repo, what
files, what commands, what does done mean?”
