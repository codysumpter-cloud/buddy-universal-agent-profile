# BUAP Diagrams

Mermaid diagrams for explaining BUAP quickly.

## Files

- `buddy-loop.mmd` — human/Buddy/Lil' Buddy/review loop.
- `source-of-truth-order.mmd` — Prismtek/Buddy source order and repo-local override.
- `capability-detection-flow.mmd` — how Buddy chooses execute, inspect, draft, or handoff mode.
- `receipts-flow.mmd` — how claims become receipts or remain unverified/blocked.
- `symphony-agent-map.mmd` — conductor and specialist role map.
