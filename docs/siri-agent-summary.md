# Siri Agent Summary

BUAP Siri support is built around two rules:

1. Siri is a surface, not the source of memory.
2. The user names both sides of the relationship.

The host app should provide memory, capabilities, and any repo/app context. The agent should ask what to call the user and what the user's Buddy should be called before it fully settles into the visible persona.

This makes BUAP usable for voice-first assistant flows while keeping the framework portable for text chat, coding agents, and app-embedded agents.
