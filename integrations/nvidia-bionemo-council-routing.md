# NVIDIA Skills + BioNeMo: Prismtek Council capability routing

## Runtime truth
This is a capability ROUTING CONTRACT, not an installed tool executor. NVIDIA Skills and NVIDIA BioNeMo Agent Toolkit are accessible in the owner's ChatGPT environment. They are **not automatically available inside Cloudflare Workers or Hermes**. Host adapters must discover and verify each tool before claiming a successful invocation.

The user requires one central NVIDIA vendor key for the Prismtek agent army. In the personal Cloudflare account the only Council vendor-key consumer is the `prismtek-api` inference broker, accessed by `prismtek-council` through a private service binding and separately generated `FLEET_GATEWAY_TOKEN`. The on-account **daily global cap is 1 call/day during pilot**, subject to evidence from D1. No profile includes raw tokens.

## Routing
- Ordinary content, marketing, email planning, project management, code review, personal workflows: use BUAP narrow specialist and the general Nemotron draft broker only if enabled, authenticated and budgeted. Do not activate BioNeMo.
- NVIDIA-specific AI-agent architecture, retrieval, inference selection, CUDA/GPU acceleration and deployment: consult NVIDIA Skill Finder and a current NVIDIA skills catalog first. Route to the matching explicitly enabled host skill only.
- Genuine biological tasks such as protein structures, docking, molecular optimization, genome analysis or molecular-generation workflows: consider a separate on-demand **BioNeMo R&D** specialist and use its individual plugin skill with scientific inputs and an owner-approved research scope. Do not run drug discovery workflows as a general business-growth agent.
- BioNeMo hosted science NIM endpoints (including `health.api.nvidia.com`) may require distinct API entitlements from general LLM inference (`integrate.api.nvidia.com`). Do not assume one NVIDIA key grants both. If one key cannot satisfy all permissions, BioNeMo remains unavailable unless the owner approves separate entitlement; never copy the work account's key.
- Research output is exploratory, not a validated therapy, safety claim, or commercial product. Preserve provenance and expert validation.

## Activation and approval
- A BUAP profile is a declaration; an operational row is a record; a running specialist needs host scheduling, active capability binding, authorization, cost cap, task and immutable receipt.
- Only research/draft/audit actions may run autonomously in the initial pilot. Emails, DMs, social publishing, charges, GitHub production deploys, security changes and personal data export always require explicit owner approval.
- Do not use Codex unless separately enabled by the user; all current Council profiles forbid it.
- Always verify a returned provider response and downstream receipt before marking a model-backed job `done`. A configured cron or API key binding alone is not execution proof.
