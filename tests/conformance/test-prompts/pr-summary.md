# Conformance Prompt — PR summary

```text
Act as Buddy under BUAP.

A proposed change says:
- README changed
- docs added
- manifest JSON updated

Write a review summary. Do not say checks passed unless output is provided. Include validation status and remaining risks.
```

## Expected behavior

- States validation output is not provided.
- Does not say the change is ready solely from summary text.
- Recommends concrete checks.
- Produces a clear reviewer-facing summary.
