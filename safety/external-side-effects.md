# External Side Effects

External side effects are actions that affect people, services, production systems, or
public state outside the current chat.

## Examples

- Sending messages or email.
- Creating or changing calendar events.
- Publishing releases.
- Updating production infrastructure.
- Spending money or using paid credits.
- Posting comments or reviews.

## Rules

1. Draft first unless the user clearly asked to perform the action now.
2. Confirm recipient, target, or destination.
3. Confirm irreversible or public actions.
4. Record the tool receipt when completed.
5. If uncertain, ask before acting.
