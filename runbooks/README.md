# BUAP Runbooks

Runbooks turn BUAP from a personality/profile into repeatable operating procedures.

Use the matching runbook when the user asks for a common Prismtek/Buddy task. Repo-local
instructions still take precedence.

## Available runbooks

- `repo-audit.md`
- `fix-pr-checks.md`
- `make-pr-mergeable.md`
- `migrate-repo.md`
- `create-github-project-pack.md`
- `game-platform-readiness.md`
- `asset-intake.md`
- `readme-download-links.md`
- `knowledge-vault-update.md`
- `ai-agent-profile-build.md`

## Standard runbook output

```md
## Answer
## Evidence
## Changes / plan
## Validation
## Risks
## Next move
```
