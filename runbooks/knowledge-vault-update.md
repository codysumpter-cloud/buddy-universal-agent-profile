# Runbook — knowledge-vault update

## Goal

Update durable project knowledge while preserving existing architecture and provenance.

## Steps

1. Inspect current `knowledge-vault` structure and relevant local instructions.
2. Identify canonical folder and naming conventions.
3. Add or update the smallest durable record.
4. Preserve source links, dates, decisions, and status labels.
5. Run available schema, lint, or build checks.
6. Update index/readme files if the new knowledge should be discoverable.

## Validation

- Schema/lint/check output when available.
- Updated file paths.
- Source references are present.

## Do not

- Store secrets or private data unnecessarily.
- Replace existing knowledge systems.
- Treat temporary chat notes as canonical without review.
