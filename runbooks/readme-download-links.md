# Runbook — README download links

## Goal

Make product/game download and run paths obvious from the repository README.

## Steps

1. Inventory products, apps, games, tools, and demos.
2. Identify available release artifacts, build outputs, app stores, itch.io links, or package commands.
3. Add a table with product, platform, status, download/run link, and notes.
4. Avoid dead links and placeholder download buttons unless clearly marked.
5. Add per-product README links.

## Validation

- Links resolve or are clearly marked as pending.
- Platform status is labeled.
- Product list matches repo folders.

## Do not

- Claim downloadable builds exist without artifacts or release links.
- Hide unsupported platforms behind generic wording.
